# 🎯 Objetivo

O objetivo deste projeto é desenvolver uma **calculadora com 20 funções diferentes utilizando o Flowgorithm**, aplicando conceitos fundamentais de lógica de programação.

O projeto foi desenvolvido para praticar:

- Variáveis;
- Operadores matemáticos;
- Entrada e saída de dados;
- Estruturas condicionais;
- Estruturas de decisão;
- Fórmulas matemáticas;
- Organização de algoritmos.

Ao iniciar o programa, o usuário recebe um **menu contendo 20 opções de cálculo**.

O usuário escolhe uma opção, informa os valores solicitados e o programa realiza automaticamente o cálculo correspondente.

⭐ Funções Obrigatórias
⚖️ 1. Cálculo do IMC

Uma das funções obrigatórias do projeto é o cálculo do Índice de Massa Corporal (IMC).

O programa solicita:

Peso do usuário;
Altura do usuário.

A fórmula utilizada é:

IMC = peso / (altura × altura)

Depois do cálculo, o resultado é apresentado ao usuário juntamente com sua classificação.

📊 Classificação do IMC
IMC	Classificação
Abaixo de 18,5	Abaixo do peso
18,5 – 24,9	Peso normal
25,0 – 29,9	Sobrepeso
30,0 – 34,9	Obesidade grau I
35,0 – 39,9	Obesidade grau II
40 ou mais	Obesidade grau III

📐 2. Cálculo de Área

A segunda função obrigatória é o cálculo de área de figuras geométricas.

O usuário informa a figura desejada e suas respectivas medidas.

Figuras utilizadas

◼️ Quadrado

Área = lado × lado

▭ Retângulo

Área = base × altura

🔺 Triângulo

Área = (base × altura) / 2

⭕ Círculo

Área = π × raio²
